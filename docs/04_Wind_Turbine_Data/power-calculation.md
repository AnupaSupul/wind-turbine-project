# Power Calculation

## The Formula

The electrical power generated by the wind turbine is calculated using the fundamental electrical power equation:

```
Power (W) = Voltage (V) × Current (A)
```

For example:
- Voltage = 8.20 V
- Current = 1.10 A
- Power = 8.20 × 1.10 = **9.02 W**

## Why Is Power Calculated by the Backend?

The **data source** (simulator or ESP32) sends the raw measurements: voltage and current. It does NOT send the calculated power value.

The **backend server** always performs the power calculation. There are two good reasons:

### 1. Data Integrity
If the ESP32 calculated power and sent it along with voltage and current, there would be a risk that the three values might not be consistent — for example, due to a rounding error or a firmware bug. By calculating power on the server, we guarantee:

```
Stored power = Stored voltage × Stored current
```

This is always true for every record in the database.

### 2. Single Source of Truth
There is only one place where the formula is applied. If the formula ever needed to change (for example, to include power factor or efficiency losses), it would only need to be changed in one place — the backend service.

## Where It Happens in the Code

The calculation is performed in `backend/src/services/telemetryService.js` inside the `saveTelemetry` function:

```javascript
const power = parseFloat((voltage * current).toFixed(4));
```

The result is rounded to 4 decimal places for storage.

## Relationship to Wind Speed

In general, higher wind speeds produce:
- Higher voltage (the generator spins faster)
- Higher current (more energy is being converted)
- Higher power (V × I increases)

This relationship is visualized in the dashboard's **Power vs Wind Speed** chart.

## Relationship to Pitch Angle

The pitch angle affects how efficiently the blades capture wind energy. There is typically an optimal pitch angle for each wind speed. This relationship is visualized in the dashboard's **Power vs Pitch Angle** chart.
